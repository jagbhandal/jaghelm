### Changed
- JagHelm no longer rewrites files in its data dir on every refresh cycle when nothing has changed, which wore SD-card and eMMC storage. The push alert snapshot (`push-snapshot.json`) is now written only when an alert state changes: a service, cron job or UPS status, a host's reachability, or a host metric crossing its threshold. The container registry behind the "last seen X ago" cards of containers that disappeared (`container-registry.json`) is written when a container appears, moves to another node, has run for a minute or is dropped, and otherwise at most every 5 minutes and on shutdown. Push alerts across a restart work as before: an incident already sent is not sent again, and a change while JagHelm was down is still sent.
- The push alert thresholds (`pushThresholds` in `display-config.json`) are now read once at start and again after each display settings save, not on every refresh cycle. If you set them by editing the file, restart JagHelm for the change to take effect.
