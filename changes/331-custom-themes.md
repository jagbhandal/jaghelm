### Added
- Settings → Appearance → Custom themes: add your own theme as JSON (pasted or from a file). It loads only if its text, status and accent colours stay readable, with the same contrast rules as the built-in themes; one that fails is rejected with the pairing it breaks, such as "text-2 on surface-1: 3.10:1, needs 4.5:1". Themes that load appear beside Dark, Light and System with a preview; rejected ones are listed apart, with the reason and a Remove button. A theme is colours only and nothing else is accepted, so a hand-edited config cannot slip a bad one in. A theme that sets its own accent turns the Accent choice off while it is in use.
