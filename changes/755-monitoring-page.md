### Added
- A Monitoring page, in the Monitor menu after Infrastructure and in the command palette. It shows how the lab is doing over time, from Prometheus, in sections that each ask a plain question: power draw and monthly cost, which disk fills first, CPU and memory by node, network, container memory growth, restarts and OOM kills, and drive health. One switch sets the range (1 hour, 24 hours, 7 days or 30 days). When an alert has a chart, a banner at the top lists it with a View graph link that scrolls to that chart and marks it; the charts show even when everything is healthy. A chart that cannot be read says so in words.
- On a phone, Monitoring is under More and opens at the same address. Power, cost, disk runway, CPU and memory are drawn for the phone, CPU and memory as a list of rows with a small trend line; the other charts say they are on a larger screen for now.
